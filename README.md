# Unit Converter

A multi-category unit converter with support for length, weight, temperature, volume, area, speed, time, digital storage, pressure, and energy.

## Features

- 10 conversion categories
- Wide range of units in each category
- Clean dark-themed web interface
- Available as both a Python script and a web tool

## Live Demo

[Try the web version here](https://unit-converter-c2afb3.netlify.app/)

## Supported Categories

- Length
- Weight / Mass
- Temperature
- Volume
- Area
- Speed
- Time
- Digital Storage
- Pressure
- Energy

## How to Use (Python)

1. Run the script
2. Choose a category
3. Enter a value
4. Select the from and to units
5. View the converted result

## Project Structure

- Python version of the converter
- Web version (HTML + JavaScript)
